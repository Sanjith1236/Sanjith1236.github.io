documentation-method

How each investigation will be documented

Each detailed report will be based on the actual exercise and evidence, rather than a generic description of the attack.

  1. Objective & scenario — what the exercise asks us to investigate.
  2. Evidence — relevant logs, alerts, screenshots, queries, or rule output.
  3. Investigation — the steps actually performed during the lab.
  4. Findings — what the available evidence supports.
  5. Response & lessons learned — suitable actions and key takeaways.
  6. MITRE ATT&CK mapping — included only when the technique is supported by the scenario.
