About me

I am a cybersecurity practitioner dedicated to Security Operations Center (SOC) workflows, practical threat detection, security monitoring, and hands-on investigation.

My practical experience is built on end-to-end, hands-on cybersecurity projects. This includes architecting network intrusion detection systems with custom Snort 3 rules for brute-force attack detection, deploying automated endpoint protection and malware quarantine workflows with ClamAV on Linux, executing structured vulnerability assessments and web penetration testing (SQL injection, XSS, and session hijacking), and deploying an AWS cloud-hosted high-interaction honeypot with decoys for SSH, WordPress, and MySQL to capture and profile live attacker activity.

I focus on understanding attacker methodologies (MITRE ATT&CK), analyzing authentication telemetry, triaging alerts, extracting actionable Indicators of Compromise (IOCs), and validating remediation. I continuously sharpen my skills through real-world blue-team labs, security research, and industry certifications including EC-Council Certified SOC Analyst (CSA) and CICSA.
